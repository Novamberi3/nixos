## Hosts:

- **nullpad:** My IdeaPad 3 15IGL05 81WQ laptop 

## Components

- **Window Manager:** [niri][niri]
- **Desktop Shell:** [Noctalia][Noctalia]
- **Terminal Emulator:** [foot][foot]
- **Shell:** [fish][fish]
- **Text Editor:** [Neovim][Neovim]
- **File Manager:** [yazi][yazi]
- **Fonts:** [ioskeley Mono][ioskeley Mono] + [font-awesome][font-awesome]
- **Color Scheme:** [gruvbox-dark][gruvbox]
- **Browser:** [Librewolf][Librewolf]
- **Notes:** [Obsidian][Obsidian]
- **Discord Client:** [Legcord][Legcord]
